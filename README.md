## About Me

I am a 4th-year Software Engineering student at **Halic University** with a strong focus on **data science, artificial intelligence, computer vision, natural language processing, speech AI, and backend systems**. I work on research-oriented machine learning projects, production-style APIs, and applied AI systems that connect experimentation with practical deployment.

- Main interests: **AI for healthcare, computer vision, multimodal learning, NLP, speech AI, cybersecurity, and model benchmarking**
- ML/DL work: **classification, object detection, VQA, image captioning, transfer learning, ensembling, and post-processing**
- Backend work: **Flask, FastAPI, .NET, REST APIs, modular ML services**
- Embedded work: **Arduino, STM32, sensor fusion, control logic, Kalman filtering**
- Research profile: [ORCID](https://orcid.org/0009-0002-0844-8355)
